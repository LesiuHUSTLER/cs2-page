CROSS.HQ — paczka startowa do nauki HTML i CSS

Co jest w środku:
- design.png -> gotowa makieta do odtworzenia
- index.html -> starter HTML z podstawową strukturą sekcji
- style.css -> starter CSS z resetem, kolorami i prostym układem
- DANE.txt -> treści do wklejenia na stronę
- KOLORY.txt -> paleta i wskazówki wizualne
- LINKI.txt -> gotowe linki do przycisków
- assets/ -> grafiki pomocnicze: logo, ikony, portrety i celowniki

Jak pracować:
1. Otwórz projekt w VS Code.
2. Uruchom index.html w przeglądarce.
3. Najpierw odtwórz header i hero.
4. Potem zbuduj siatkę kart zawodników.
5. Na końcu dodaj sekcję poradnika i FAQ.

Ważne:
- To jest projekt treningowy dla początkującego.
- Nie musisz odwzorować wszystkiego 1:1.
- Najłatwiej zrobić wersję desktopową, a mobile dopiero później.
- Portrety zostały wycięte z zaakceptowanej makiety, żebyś miał gotowe assety do użycia.
